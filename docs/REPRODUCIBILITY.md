# Reproduction and implementation notes

## Scope

This repository provides a clean research implementation of the DMA-PULSE pipeline described in the published paper. It is intended to make the architecture and experimental workflow understandable and executable without distributing the original PULSE dataset.

The repository is **not the original authors' experimental codebase**, and the current implementation should not be described as an exact reproduction of the published benchmark.

## Published experimental setup

The paper describes:

- 14,010 synthetic PULSE activity sequences
- 5 sequential time steps
- 11 final feature dimensions
- binary and four-class evaluation
- minority oversampling and majority undersampling
- an 80:20 train-test split
- a self-attention Transformer
- sequential AOA global search followed by RFO local refinement

## Local dataset format

Training utilities accept a NumPy `.npz` file containing:

```text
X: float32 array [N, 5, 11]
y: int64 array [N]
```

The original PULSE data should not be committed to this repository unless distribution rights and provenance are established.

## Reproducing the published numbers

The README labels the paper's reported metrics explicitly. To claim an independent reproduction, the following should be recorded in a future experiment artifact:

1. exact dataset provenance;
2. preprocessing configuration;
3. train/test split;
4. random seeds;
5. Transformer hyperparameters;
6. AOA search configuration;
7. RFO search configuration;
8. training budget and stopping criteria;
9. evaluation script and generated metrics.

Until those conditions are satisfied, results generated by this repository should be reported as **repository experiments**, not as reproduced paper results.
